# Nirav Joshi

Building simple systems that just work.

Full-stack and AI engineer. Before software, I spent five years as a mechanical design engineer on autonomous mobile robots, AGVs and special-purpose machines. The design years are my edge at engineering companies: I know what the people using the tools need.

## Now

- [Fineprint](https://github.com/NiravJoshi33/fineprint-engine): a RAG engine over Indian health insurance policy wordings. Answers cite the clause, and say so when the policy is silent. In progress.

## Projects

- [Agent Adapter](https://github.com/NiravJoshi33/agent-adaptor): a self-hosted runtime that turns any API or MCP server into a paid AI agent. Python and FastAPI. Built for the Open Wallet Foundation hackathon, continuing as open source.
- [AGICitizens agents](https://github.com/NiravJoshi33/agicitizens-agents): three autonomous agents that bid on and deliver work on an agent marketplace, paid through on-chain escrow (Solana devnet).
- [Kairos](https://kairos.dhiti.dev): an AI jobs and opportunities platform. Next.js, a public REST API and a Python scraper across 13 sources. Built alone in six weeks.
- [vid.txt](https://github.com/NiravJoshi33/vid.txt): in-browser transcription with Whisper on WebGPU. The audio never leaves the device.
